# TripSync Testing

This folder contains testing documentation for the TripSync application.

## Testing Areas

### 1. Authentication
- User signup
- User login
- User logout
- Invalid login

### 2. Trip Features
- Create a trip
- Add friends
- View trips

### 3. Trip Planning Features
- Shared itinerary
- Expense tracker
- Group voting
- Trip checklist

## Testing Process

Each feature will be tested by running the TripSync application and verifying that the expected result occurs.

Test results will be recorded as Pass or Fail.

Any failed tests will be documented and retested after the issue is corrected.
